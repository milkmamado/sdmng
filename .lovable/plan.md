# CRM 연동 화면 정리 및 사용자 메뉴얼 최신화

## 변경 범위
- 사이드바의 「패키지 연동」 항목만 숨기고 기존 페이지와 경로는 유지합니다.
- 관리환자 목록과 환자 상세 화면에서 예전 패키지 「최신화」 버튼 JSX만 제거합니다.
- 버튼 위치에는 「패키지는 CRM 일괄 동기화로 자동 반영됩니다.」 안내를 표시합니다.
- 패키지 메시지 수신, 저장 함수, 상태값, 수동 거래 관리, 요약 표시는 그대로 둡니다.
- 다른 수동 CRM 진입점은 수정하지 않고 최종 보고에 목록만 남깁니다.

## 안내서 개편
- `UserManual`과 `CRMBookmarklet`을 현재 CRM 연동 방식에 맞춰 다시 씁니다.
- CRM 북마크 하나의 두 가지 쓰임새, 기본정보·입원정보·패키지 동기화 범위와 미리보기 확인 항목을 반영합니다.
- 패키지 관리, 일별 환자 관리, 통계 정의, 진단·병원 분류, 초진 등록 설명을 현재 동작과 일치시킵니다.
- 대시보드·이탈 리스크·면책·이탈 환자 스케줄 설명도 실제 화면 동작을 기준으로 바로잡습니다.
- 기존 Card, Badge, 색상 박스 등 화면 스타일은 유지합니다.

## 보호 범위 및 확인
- 매출·통계·CRM 동기화 계산 로직과 기존 패키지 처리 함수는 변경하지 않습니다.
- 파일·함수·경로는 삭제하지 않습니다.
- 변경 후 패키지 수신 함수와 상태값이 남아 있는지 검색하고, 타입 검사와 빌드를 확인합니다.
- 최종 보고에 변경 파일, 제거한 JSX, 수정하지 않은 구형 CRM 진입점을 정리합니다.
